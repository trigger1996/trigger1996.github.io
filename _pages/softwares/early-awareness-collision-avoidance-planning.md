Brief introduction:

`Early-Awareness Collision-Avoidance Planning` provides a safety-guaranteed offline planning method for robotic systems subject to linear temporal logic (LTL) specifications. `LOMAP-Custom` contains the theoretical implementation and case studies, while `amigobot_LTL` provides the physical-experiment implementation on the AmigoBot platform.
